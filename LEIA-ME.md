# Como levar para o Claude Code

1. Baixe o arquivo `dcompositos-projetos.zip` no computador e descompacte.
2. Abra o Claude Code na pasta do seu repositório `Projeto-e-c-lculo-estrutural-` (ou em uma pasta nova).
3. Copie para dentro dela os arquivos da pasta descompactada.
4. Cole no Claude Code a mensagem curta que está no chat (ela manda ele ler o PROMPT-CLAUDE-CODE.md).
5. Ele faz a versão de teste e te mostra. Você testa no celular e aprova.
6. Para mudar qualquer coisa depois, é só pedir para ele, citando a seção do PROMPT (ex.: "seção 3, troque o motor de referência").

Parâmetros padrão da filamentadora (mudam no próprio app, em Configuração):
- Tanque Ø 3000 × 6000 mm · máquina máx. Ø 3000 × 6000 · folga 500
- Automática: 8 fios · banda 100 mm · CLP Delta + IHM · motorredutor + encoder · carro passo
- Semiautomática: tecido biaxial 1808 · largura 1200 · sobreposição 100 · timer · carro manual
- Dimensionamento: 30 N por fio · 1000 kg · 10 rpm · carro 30000 mm/min · cremalheira módulo 2 · pinhão 20 dentes
